# ZUUN Studio — Design in Motion

موقع وكالة ZUUN بخمس صفحات، بالعربية (RTL) والإنجليزية (LTR). العربية هي النسخة الافتراضية. زر اللغة يبدّل لغة الصفحة الحالية ويحافظ على التخصص المحدد في المعرض أو نموذج التواصل.

| الصفحة | العربية | English |
| --- | --- | --- |
| الرئيسية | `/` | `/en` |
| معرض الأعمال | `/work` | `/en/work` |
| الفريق | `/team` | `/en/team` |
| المؤسس | `/founder` | `/en/founder` |
| التواصل | `/contact` | `/en/contact` |

## التشغيل / Running the site

المتطلبات: Node.js 20.19+ أو 22.12+.

```sh
npm ci
npm run build
npm start
```

المنفذ الافتراضي `4173`، ويمكن تغييره بمتغيّر `PORT`. شغّل `npm run dev` أثناء التعديل. ملف ZIP يحتوي على ملفات المصدر، ولا يشمل الاعتماديات أو البناء الناتج أو صندوق الاستفسارات.

## الحركة والمشاهد / Motion and 3D

- الافتتاحية كتابة ثلاثية الأبعاد تُرسم مباشرةً، وليست فيديو. أثناء التمرير تتحوّل حروف `ZUUN.` إلى خيوط تتجمّع في شكل صقر الشعار. الرموز الأربعة تحت الحروف تمثّل تطوير الواجهات، التصميم، الأتمتة، وتطبيقات الموبايل.
- في المعرض، تنقّل بالأسهم أو بالتمرير الأفقي. اسحب المجسّم لتغيير زاويته؛ على شاشة اللمس اضغط **تدوير المجسّم** أولًا كي لا يتعارض السحب مع تصفّح المعرض. بالمفاتيح، ركّز على المجسّم واستخدم الأسهم، أو `Home` لإعادة زاوية العرض. اضغط اسم النموذج أو السهم بجانبه لفتح التفاصيل.
- **تشغيل / إيقاف** في شريط التنقّل يتحكّم في الحركة التلقائية، والموقع يبدأ بدون حركة تلقائية عند تفعيل تفضيل «تقليل الحركة» على الجهاز. التحكم اليدوي يظل متاحًا.
- محرّك Three.js يُحمّل عند الحاجة ويرسم المشاهد المرئية في طبقة WebGL2 مشتركة. تحويل الحروف يتبع موضع التمرير مباشرة، ودقّة طبقة الرسم تتكيّف مع أداء الجهاز. يتوقّف الرسم المستمر خارج المشهد أو أثناء إيقاف الحركة، مع إعادة الرسم عند السحب أو استخدام المفاتيح. بدون WebGL تبقى الصفحات والنموذج متاحين، وتُعرض كتابة CSS وصور المعرض بدل المجسّمات.
- إضاءة المشاهد مجهّزة مسبقًا في `public/media/studio-light.bin` بدل حسابها عند فتح الصفحة. الملف خريطة CubeUV بحجم 336×128 بصيغة RGBA16F خطّية، مُستخرجة من Three.js RoomEnvironment.
- `npm run build` يجهّز نسخ Brotli وgzip من ملفات JavaScript وCSS وخريطة الإضاءة. الخادم المضمّن يرسل النسخة المدعومة تلقائيًا؛ على استضافة أخرى يمكن تفعيل ضغط الملفات عبر الخادم أو الـCDN.

## تحديث المحتوى / Updating content

- النصوص والتخصصات وأعضاء الفريق ونماذج الأعمال: `src/content.js`. النماذج الحالية توضيحية وليست أعمالًا منشورة لعملاء. أعداد العملاء وآراؤهم غير منشورة؛ أضفها بعد توفّر بيانات مؤكّدة.
- الشعار والصور: `public/media/`. الملف `src/world/wordmark-data.json` يحفظ مسارات الحروف من خط Manrope وأثر الصقر المستخرج من شعار ZUUN لاستخدامها في مجسّم الافتتاحية.
- تصميم وترقيم الأقسام: `src/editorial.jsx` و`src/editorial.css`. المشاهد: `src/world/`. الخطوط مستضافة داخل المشروع؛ التراخيص في `licenses/`.

### الهويات البصرية / Visual identities

- افتح `/work?field=identity` أو `/en/work?field=identity` لعرض **رِواق للقهوة (Riwaq Roastery)** و**مهرجان طَيْف (Tayf Festival)**. التصميمان نماذج من الاستوديو، وليسَا أعمالًا لعملاء. لكل نموذج مجسّم قابل للتدوير، ولوحة تطبيقات ثابتة في التفاصيل، ولوحة ألوان بأكواد HEX.
- ألوان الطباعة والمجسّمات: `src/identities.js`. رسومات الشعار وقوالب الطباعة المستخدمة على المجسّمات: `src/identity-art.js`. صور العرض الاحتياطية تنتهي بـ `-cover.webp`، ولوحات التفاصيل هي `riwaq.webp` و`tayf.webp` في `public/media/`.
- تخصصات المعرض واختيارات نموذج التواصل تتشارك القائمة `services` في `src/content.js`. طلب تصميم هوية يفتح `/contact?service=identity` بالخدمة محددة مسبقًا. خط Cormorant Garamond مستضاف محليًا من Google Fonts، وترخيصه في `licenses/cormorantgaramond-OFL.txt`.

## رسائل التواصل / Contact inbox

النموذج يرسل الاستفسار إلى `POST /api/contact`. الخادم يتحقّق من الحقول ويحفظ الرسالة في `var/inquiries.jsonl` افتراضيًا (خارج ملفات الموقع المنشورة). لقراءة الرسائل على الخادم:

```sh
npm run inbox
```

عند الاستضافة، اضبط `ZUUN_DATA_DIR` على مساحة تخزين دائمة وخاصة، وحدّد الوصول والنسخ الاحتياطية وفق سياسة الخصوصية الخاصة بك. النموذج لا يرسل بريدًا تلقائيًا إلا بعد تفعيل إعدادات البريد. للتنبيه عبر Resend، اضبط `RESEND_API_KEY` و`ZUUN_NOTIFY_FROM` (عنوان من نطاق موثّق) و`ZUUN_NOTIFY_TO` في بيئة الخادم. لا تضع المفاتيح في الواجهة. راجع `.env.example`؛ إذا حفظت الإعدادات محليًا في `.env` يمكنك التشغيل باستخدام `node --env-file=.env server.mjs`، وقراءة الصندوق باستخدام `node --env-file=.env scripts/inbox.mjs`.

The included Node server serves the built site and records contact messages in a private inbox. Use a persistent `ZUUN_DATA_DIR` in production and optionally configure Resend to receive email notifications. On static-only hosting, configure route rewrites and connect the form to a separate backend.
